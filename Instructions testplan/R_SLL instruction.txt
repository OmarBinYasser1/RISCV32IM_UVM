8. Shifted-out bits — P0
SLL is a logical shift, so bits shifted beyond bit 31 are discarded.

0x80000000 << 1 = 0x00000000
0xFFFFFFFF << 1 = 0xFFFFFFFE
0xFFFFFFFF << 4 = 0xFFFFFFF0

14. Back-to-back dependency (Pipelined)

This is especially important if your core is pipelined.

Example:
ADD x5, x1, x2
SLL x6, x5, x3
Expected
x5 = x1 + x2
x6 = x5 << x3[4:0]

 also test:
